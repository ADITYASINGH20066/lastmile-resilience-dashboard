# PHASE 0 — EXECUTION

1. Back up the current frontend files.
2. Extract this package from the repository root.
3. Run `npm run build`.
4. Start FastAPI and Vite.
5. Verify `/health`, `/dashboard/summary`, `/alerts/active`, `/rivers/DESANG/stations`, `/rivers/DESANG/villages`.
6. Confirm the existing UI is visually unchanged. Phase 0 is foundation-only.
7. Freeze this baseline and begin Phase 1 Command View.

Important: do not replace `.env.local`. The package only includes `.env.example`.
